# オセロニア デッキ編成プランナー（othellonia-deck-planner）

「逆転オセロニア」のデッキ編成案をChatGPT等のAIに調べてもらい、気に入った編成を追跡して
「所持チェック」「未所持駒の代替案」「入手方法メモ」を端末内に保存しておくためのPWAです。
[othellonia-inventory](https://github.com/masatto/othellonia-inventory)（所持駒管理アプリ）
とは別の、単独で完結するツールです。所持駒データベースは持たず、追跡したいデッキの中だけで
その場ごとに所持チェックを付ける軽量な設計にしています。

- 月額運用費0円（GitHub Free + GitHub Pagesのみ）
- 通常利用でOpenAI APIなど有料サービスを使用しません
- ChatGPTへの相談は、アプリが生成したプロンプトを**あなたが手動でコピー＆ペースト**する方式です
- Webサイトを自動巡回して情報を取得する機能は含まれていません（プロンプト経由の調査のみ）

## 使い方

### 1. デッキを探す

1. 「デッキを探す」タブを開く
2. テーマ・条件（任意）を入力し、「プロンプトを生成する」を押す
3. 表示されたプロンプトをコピーし、ChatGPT等に貼り付けて実行する（**アプリからは何も送信
   されません**。コピーしてから先はあなたの操作です）
4. ChatGPTの回答（JSON）をコピーし、「ChatGPTの回答（JSON）を取り込む」から貼り付けて
   「検証する」
5. 表示された候補から、追跡したいデッキを選んで「このデッキを追跡する」を押す

### 2. 所持チェックを付ける

デッキ詳細画面で、各駒の左のチェックボックスをタップして所持状況を記録します。
このアプリは全キャラクターの所持駒データベースを持たないため、デッキごとにその場で
チェックする方式です（別アプリとの連携やデータ入力は不要です）。

### 3. 未所持の駒を調べる

1. デッキ詳細画面の「🔍 未所持駒を調査する」を押す
2. 表示されたプロンプトをChatGPT等に貼り付けて実行する（入手方法・代用候補をまとめて
   調査します）
3. 回答のJSONを取り込むと、各駒に「入手方法」のメモと、最大3件までの「代用候補」
   （候補名・代用できる理由・その候補自体の入手方法）が保存されます

**代用候補も、元の駒と同じように所持チェックできます。** 代用候補は初期状態では折りたたみ
表示になっており、「▶ 代用候補（n件、所持m件）」を押すと開閉できます。代用候補ごとに
「所持している」チェックボックスがあり、実際に
代用候補を持っているかどうかを個別に管理できます。再調査すると入手方法等は最新の内容に
更新されますが、同じ名前の代用候補が引き続き提案された場合、それまでのチェック状態は
引き継がれます。

件数が多い場合は複数バッチに分けてプロンプトを生成します（1回あたりの調査が重くなり
ChatGPT側の応答が不安定になるのを防ぐため）。**1つのバッチを反映したあとも同じプロンプト
一覧の画面に留まる**ので、プロンプトを生成し直すことなく、続けて次のバッチの回答を
「ChatGPTの回答（JSON）を取り込む」から貼り付けられます。反映済みのバッチには「✓ 反映済み」
と表示されます。

### 4. 代用で対応可能な枠を確認する

本体は未所持でも、所持している代用候補が1件でもあれば、その枠には自動で
「代用で対応可能」タグが表示されます。デッキ詳細画面の上部にも「代用込み: n / 総数」の
件数が表示され、本体所持数とは別に実質的な充足度を確認できます（新たにAIへ調査を
依頼するものではなく、既存の所持チェックだけで計算しています）。

### 5. 不足駒まとめを確認する

複数のデッキを追跡している場合、ホーム画面の「📊 不足駒まとめを見る」から、まだ所持して
おらず代用でも対応できていない駒を全デッキ横断で確認できます。複数のデッキで必要と
されている駒ほど上位に表示されるため、次に何を優先して入手すべきかの判断に使えます
（こちらも既存データだけで計算しており、AIへの再調査は不要です）。

### 4. バックアップする

Safariのサイトデータ削除・機種変更・PWAの再インストールで、端末内のデータは失われます。
「バックアップ」タブから定期的にJSONファイルを保存してください。

## データの保存場所と注意事項

- すべてのデータ（追跡中のデッキ・所持チェック・メモ）は **この端末のSafari（IndexedDB）内
  だけ** に保存されます
- GitHubや外部サーバーには、デッキデータ・調査結果のいずれも送信されません
- ChatGPT等への送信は、あなたが生成したプロンプトを手動でコピー＆ペーストした場合のみ
  行われます
- Safariの「Webサイトデータを消去」を行うと、この端末内のデータは失われます。必ず定期的に
  バックアップを保存してください

## Webサイトの自動巡回について

このアプリにWebサイトを自動巡回・スクレイピングする機能は含まれていません。デッキ編成案・
代替案・入手方法はすべて、あなたがChatGPT等へ手動で依頼した調査結果を貼り付けることで
取り込みます。

## 開発者向けセットアップ

### 前提

- Node.js 22系
- npm

### セットアップ

```bash
npm ci
npm run dev       # 開発サーバー起動（http://localhost:5173 ）
```

### ビルド

```bash
npm run build         # ローカル確認用（base: "/"）
npm run build:pages   # GitHub Pages公開用（base: "/othellonia-deck-planner/"）
```

### テスト

```bash
npm run test           # 単体テスト（Vitest）
npm run test:watch     # watchモード
npm run test:e2e       # E2E（Playwright、iPhone SE/15/15 Pro Max相当のビューポートで実行）
```

Playwright実行前に、対象ブラウザをインストールしていない環境では `npx playwright install chromium`
を実行してください（このリポジトリのCIでは自動実行されます）。

### 公開物の安全性チェック

```bash
npm run check:secrets   # 秘密情報（APIキー等）混入チェック
npm run check:pwa       # PWA設定（manifest/Service Worker等）チェック
```

### アイコンの再生成

```bash
npm run icons    # 自作SVGからPWAアイコンPNGを再生成（ネットワーク不使用）
```

### ディレクトリ構成

```
src/
  domain/        ドメイン型定義・デッキ構築ロジック
  db/            IndexedDBアクセス層（idb）
  prompts/       プロンプト生成・AI回答のJSON検証（Zod）・JSON抽出
  state/         React Context（追跡中デッキの状態管理）
  pages/         画面コンポーネント（デッキ一覧/探索/詳細/不足駒まとめ/バックアップ）
  components/    共通UIコンポーネント
  backup/        バックアップ/復元・共有処理
public/
  icons/         自作PWAアイコン（source.svgから生成）
tools/           PWAアイコン生成スクリプト
scripts/         CI用の公開物安全性チェックスクリプト
tests/
  unit/          Vitest単体テスト
  e2e/           Playwright E2Eテスト
.github/workflows/
  ci.yml         lint/型チェック/テスト/ビルド/公開物安全性検査
  deploy.yml     GitHub Pagesへのデプロイ
```

### React Routerについて

GitHub Pagesはサブパス配信かつサーバー側リライトができないため、`HashRouter` を採用して
います（`/#/deck/xxxx` のようなURLになります）。

## GitHub Pagesへのデプロイ手順

1. GitHubにログインする
2. このリポジトリ（`othellonia-deck-planner`）の Settings → Pages を開く
3. 「Build and deployment」の Source を「GitHub Actions」に変更する
4. `main` ブランチへプッシュする（`.github/workflows/deploy.yml` が自動実行されます）
5. Actionsタブでワークフローの成功を確認し、表示される公開URLにアクセスする

以降は `main` ブランチへの変更のたびに自動で再デプロイされます。
